# Clearcut

A private iPhone app for batch product photos: Apple's own subject cutout, backdrops, shadows and one-tap export to the camera roll.

## Getting a new version onto the phone

Every change pushed to `main` is built automatically. When the build finishes, the **latest** release on this repository holds a fresh `Clearcut.ipa`.

1. On the iPhone, open this repository's Releases page and download `Clearcut.ipa`.
2. Tap the download, choose Share, then SideStore. SideStore installs it over the old version.

## First install (once)

1. On the PC, install iLoader from iloader.app (the Linux AppImage).
2. Plug the iPhone in with a cable, open iLoader, sign in with your Apple ID and choose Install SideStore.
3. On the iPhone, open Settings, General, VPN & Device Management, and trust your Apple ID. Turn on Developer Mode if asked (Settings, Privacy & Security).
4. Install Clearcut through SideStore as above.

SideStore renews the app every few days by itself, so the 7-day limit on free installs never bites.
