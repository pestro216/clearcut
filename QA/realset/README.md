Real photos from Woolfall stock with reference cutouts: the test set that decides whether a change
to the cutout engine ships. Add each with `tools/add_real_photo.py`. Every quality run scores them
as scenes named `R_<folder>`. Compare two runs with `tools/compare_runs.py`.

Aim for 30 to 50 photos covering the range: dark items on dark or grey floors, light items on
light surfaces, knits and fuzzy edges, mannequin and worn shots, items touching the frame edge,
close-ups, hangers and tags in shot, busy and plain backgrounds, good and poor light.
